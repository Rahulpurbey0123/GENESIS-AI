## DIP v1.1 Hash Reproducibility Fix Summary

### Problem Discovered
The dataset SHA-256 hashes generated by `compute_dataset_hash` depended on OS-specific line endings (`\r\n` on Windows vs `\n` on Linux/macOS) because `to_csv(index=False)` did not specify an explicit line terminator. This led to potential cross-platform hash mismatches.

### Canonical Dataset Hash Definition
Established ONE cross-platform deterministic canonical dataset-content hashing procedure:
1. Reindex DataFrame columns in alphabetical sorted order (`df.reindex(sorted(df.columns), axis=1)`).
2. Exclude DataFrame index (`index=False`).
3. Explicitly specify Unix line endings (`lineterminator='\n'`).
4. Encode as UTF-8 bytes (`.encode("utf-8")`).
5. Compute SHA-256 hex digest (`hashlib.sha256().hexdigest()`).
