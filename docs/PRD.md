# GENESIS-AI -- Product Requirements Document (PRD)

## Vision
Build a research-oriented AutoML framework that first understands a dataset using a Dataset Intelligence Profile (DIP), then intelligently narrows the search space before optimization.

## Problem
Traditional AutoML wastes computation by evaluating many unnecessary pipelines.

## Goal
Reduce search time and evaluated pipelines while maintaining comparable predictive performance.

## Target Users
- Students
- Researchers
- Data Scientists
- Educators

## Core Features
1. CSV upload
2. Dataset Intelligence Profile (DIP)
3. Intelligent model recommendation
4. Genetic Algorithm optimization
5. Explainability (SHAP, metrics)
6. LLM-powered explanations
7. Experiment history

## Success Metrics
- 50--70% fewer evaluated pipelines
- 30--50% lower search time
- Accuracy within 1--2% of AutoML baselines
